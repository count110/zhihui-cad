# XDATA 实测步骤（10.17 前完成，负责：B + E）

目的：确认用户在 CAD 软件里打开、编辑、另存之后，我们写进 DXF 的语义标签还在。改图能不能做准，取决于这一步。

## 测试软件（至少两款）
1. AutoCAD 或中望CAD（国内评委常用，二选一，有条件两个都测）
2. LibreCAD 或 QCAD（开源软件）

## 步骤
1. 生成探针图：
   ```bash
   .venv/Scripts/python 06_测试与基准用例/xdata_probe/probe.py make
   ```
2. 用 CAD 软件打开 `out/probe.dxf`，依次做下面三件事：
   - 点选一台设备，查看属性面板里能不能看到 TAG / NAME；
   - 把引风机 F-201 往右拖一段；
   - 另存为 DXF（AutoCAD 选 2018 DXF），文件名写成 `probe_<软件名>.dxf`。
3. 检查：
   ```bash
   .venv/Scripts/python 06_测试与基准用例/xdata_probe/probe.py check out/probe_<软件名>.dxf
   ```
4. 把终端输出贴进下表。
