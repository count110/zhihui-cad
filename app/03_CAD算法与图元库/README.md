## 填充（HATCH）
对标 AutoCAD 的 HATCH / BHATCH。核心在 `zhihui/cad/hatch.py`（纯函数，不依赖 CAD-IR），接入图纸在 `zhihui/cad/hatch_ir.py`。
效果对照：[填充效果.png](填充效果.png)（上：参考图与 W001 全图；下：主流程局部）。

**定边界的两种方式**（工具 `add_hatch`）
| 方式 | 参数 | 做法 |
|---|---|---|
| 拾取点 | `pick={"anchor": "T-101", "dx": 0, "dy": -5}`（相对设备中心，图纸 mm；也可锚在连接上，取最长段中点）或 `pick={"x", "y"}`（绝对，模型 mm） | 拾取点附近的图形打散成折线（误差 0.05 图纸 mm）→ 求交 → `polygonize` 拼面，取包含拾取点的最小面；外环是边界，内环是孤岛。用 STRtree 从拾取点开窗口，面完全落在窗口里才算数，否则窗口加倍 |
| 选对象 | `select=["E3", "C5"]` | 闭合图形直接作边界（圆、闭合多段线、整椭圆、闭合样条）；选设备时取图元里最大的闭合轮廓。不闭合报 `E_HATCH_NOT_CLOSED` |

- **孤岛方式** `style`：`normal` 奇偶交替（默认）/ `outer` 只填最外层 / `ignore` 忽略孤岛，对应 HATCH 的 `hatch_style` 0 / 1 / 2，写哪些孤岛边界也按这个规则。
- **缺口容差** `gap_tol`（图纸 mm，对应 HPGAPTOL）：拼面前把距离小于它的悬空端点接到最近的线上。找不到封闭区域时报 `E_HATCH_NO_BOUNDARY`，
  `detail.gaps` 列出离拾取点最近的缺口（位置、两端坐标、长度），hint 形如「(98.5, 60.0) 处有 1.20 mm 缺口……」。拾取点压在线上报 `E_HATCH_ON_BOUNDARY`。
- **不压字**：区域里的文字（含块里的文字和可见属性）包围盒外扩 1 图纸 mm 后挖掉。
- **精确边界**：边界正好是一整个圆 / 椭圆 / 闭合多段线时，写原图形（边界路径里是真圆弧、多段线保留 bulge），否则写打散后的折线。

**图案与比例**：ezdxf 自带 172 种标准图案 + `SOLID` 纯色；图案名写错报 `E_BAD_ARG`，hint 给最接近的 5 个（l/I 与 1、O 与 0 视为易混字符）。
对外只用「图纸上的线距」`paper_spacing`（mm，默认 3），内部换算：`scale = d.unit × paper_spacing ÷ 基准线距`。
基准线距取图案各组平行线线距的最大值，也就是图案的重复间距；只有一组线或各组等距的图案就是线距本身。

| 材料 | 图案 | 基准线距 | 本库用的图纸线距 |
|---|---|---|---|
| 钢筋混凝土（池壁、池底、挡土墙） | ANSI31 + AR-CONC 叠两层 | 3.175 / 280.89 | 0.8～1.2 / 4 |
| 素土（地面） | EARTH | 6.35 | 2 |
| 砂（滤料） | AR-SAND | 68.02 | 6 |
| 卵石（承托层） | GRAVEL | 25.4 | 8（太小会被渲染成实心，见下） |

**关联**：DXF 每次都从 IR 重新生成。每次工具改完图、每次出图，都按「锚点当前位置 + pick_rel」重新拾取一次，所以设备移动、换图元、重新布局后填充跟着走（有变化的填充自动并入改图的影响集）。
求不出边界时标记 `disassociated`，沿用上一次求出的边界照常画，`validate_drawing` 给 `W_HATCH_DISASSOCIATED` 警告，差异报告的 `hatches.disassociated` 里列出；
之后边界恢复了会自动重新关联（AutoCAD 是一旦失去关联就不再恢复）。锚在设备 / 管线上的填充不认图框和标题栏的线：边界被改开口时宁可失去关联，也不悄悄扩成「图框里的一大片」。

**图元里的填充**：图元 JSON 的 graphics 可写 `{"type": "hatch", "boundary": [[x, y], ...], "holes": [[...]], "pattern": "ANSI31", "paper_spacing": 2, "angle": 45}`，画进块里，总览图同样显示。
给水构筑物已用上：絮凝沉淀池池壁 / 池底 / 中隔墙、清水池池壁和顶底板、集水井井壁（混凝土）、无阀滤池滤料（AR-SAND）和承托层（GRAVEL）、挡土墙。
高程布置图的地面线下方是 EARTH；地面台阶处（如沉淀池 288.40 跌到滤池 286.00）自动画一道带混凝土剖面线的挡土墙。

**DXF**：图层 HATCH（细线 0.18、颜色 8），XDATA = `["hatch", hid, anchor_ref, pick_rel, pattern, paper_spacing, angle, style, mode, boundary_refs, gap_tol, layer]`，`read_dxf` 还原成 CAD-IR 的 `Hatch`。
**渲染**：`hatching_timeout=10` 秒；`min_hatch_line_distance` = 0.2 图纸 mm，比这更密的图案画成实心，防止拖慢或糊成一团。

**已知限制**
- 没有渐变填充；不能设图案原点（用默认原点）。
- 上传的外来 DXF 里的填充只读不改（读回时提示数量）。
- 仓库里还没有通用命令层（LINE / TRIM 等），`HATCH ANSI31 S3 A0 PICK 120,80` 这类命令行写法没有接入；以后接命令层时直接调 `hatch.py` / `hatch_ir.py` 的同一套函数。
- 拾取求边界看的是图上所有线（含半箭头、引线等），极少数情况下会被这些短线切出比预期小的区域；需要时改用 select 或调整拾取点。
- GRAVEL 之类不规则图案最密的那组线远比重复间距小，图纸线距给小了会触发「过密改实心」，卵石要 ≥ 6 mm 左右。
