# 智绘CAD 多智能体对比与验收

日期：2026-10-18。以实际 JSON 事件、真实失败数据库导出用例与部署包内测试为证据。

## 评测口径
- 同一 S001～S010 提示及输入图纸，single 和 multi 都使用共享的 40 次工具 / 180 秒预算；校验和导出也计入调用。
- Mock single 对 S001～S005 注入历史错误序列，验证熔断机制；Mock multi 直接处理原提示。二者是故障重放与正常流水线测试，不能据此声称模型智能提升。
- 真实模式均直接使用原提示与相同输入，调用 DeepSeek。模型 ID 来自本机环境配置；此次实测为 deepseek-flash。未提供 Qwen Key，因此 Qwen 备份切换未做真实网络验收，仅保留已有单元测试与切换实现。
- 10/10 指符合各例的稳健性终态、预算和产物断言，包含等待确认，绝不等同 100% 出图。READY、警告交付、失败和等待确认单列。每组仅 10 例、每例一次；不作统计显著性或通用质量承诺。
- 原始首轮 multi 数据也保留。首轮发现中文标题栏字段、未知设备降级与模型重复转写长清单的不足；修正后完整重跑的 multi_final 为最终组，未用单例最优值拼接。
- Token 为返回 usage 的已观测消耗；中途超时请求若未返回 usage，其可能的计费不在该数内。

## 架构与交付范围
- M2：用户事实护栏下的标题栏和标注编辑、确认删除、命名填充、标题栏检索；62 个图元端口补语义，关键设备补闭合区域与总览。
- M3：本地 BM25 + 中文二元词、别名及首字母检索，8 类模板、能力目录、缺口落库和 resolve 自动回归闭环。模板未标示为已批准设计；无来源数值禁止进入图纸。
- M4：Pydantic ProcessSpec、持久化黑板、Python 状态机、10 个独立角色配置（builder/editor 分开），编译和布局由程序执行；模型输出非法 JSON 仅重试一次后规则兜底。可选视觉审查需另配 VL，当前无对应视觉模型 Key，未做真实图像模型验收。
- M5：默认 multi，可配置 single；角色时间线、可增删编辑的方案表、报告、橙色警告交付、只读知识缺口看板；确认内容写回 user_facts。
- M6：评测 CLI、原始事件、对比报告和内置 Python 的 dist_offline；本机 DeepSeek 凭据单独配置，交付压缩包无密钥/历史用户库。
