# 化工设备图 设计说明（P0：立式/卧式储罐方案图）

> 2026-10-20 起草，依据 `化工设备图能力_改造提示词_v1.md`（下称“任务书”）。本文只写设计决定和与任务书不同的地方；规则表、字段分级的全文以任务书第 4 节为准。
> 用户对任务书第 14 节的答复（2026-10-20）：标准数据先按公开资料/经验值录入并标 `verified:false`、图上注明“未核对”；方位 0° 朝上、顺时针（卧式从左封头端看）；管口符号 a/b/c；GB/T 10609.1 + HG 附加栏；接管 B 系列；尺寸基准取环焊缝；P1 做壁厚估算（许用应力表先用公开资料、标未核对）；不新增依赖。

## 1 数据模型

- `zhihui/ir/vessel.py`：存储模型 `VesselSpec`（`DesignData / Shell / Head / Nozzle / Support / Internals`），入参模型 `VesselPatchIn`（`DesignDataIn / ShellIn / HeadIn / NozzleIn / SupportIn`）。全部 `extra="forbid"`。
- `Drawing.vessel: VesselSpec | None = None`，加进 `_NEW_DRAWING_FIELDS`；图纸仍是 `mode="general"`。
- 数值字段在入参里可以写数、`{"value":1.6,"unit":"m"}` 或 `"600kPa"`，由 `spec_ops` 换算成 mm / MPa / ℃。
- 与任务书的差异（实现需要）：
  - `Nozzle.uid`、`Support.uid`：内部稳定编号（n1、n2…；s1、s2…），只由程序写。`sources` 的键用它（`nozzles[n3].dn`），对外展示时换成管口符号（`nozzles[b].dn`）。原因：管口符号要等位置规则算完才分配，而来源在合并补丁时就要记。
  - `VesselSpec.drawing` 里另存 `marks_assigned`、`detached`（被用户手工删掉的生成图元编号，重新生成时不再画）。

## 2 默认规则

`zhihui/cad/equipment/rules.py`，每条一个函数，汇总在 `RULES`；经验数值在 `data/rules.json`（每项带 `source` 和 `verified`，目前全部 `verified:false`）。
计算顺序：R-HEAD-01/02 → R-MAT-01 → R-LEN-01 → R-SUP-01/02/POS → R-NOZ-LOC → R-NOZ-POS → R-NOZ-ORI-01 → R-NOZ-PROJ-01 → R-PIPE-01 → R-PN-01 → R-FLG-01 → R-MH-01 → R-STD-01 → **R-MARK-01**。
与任务书顺序的唯一差异：R-MARK-01 放到最后，因为“主视图左下方起顺时针”要用到管口在主视图里的位置。已分配的符号不重排。
规则值的来源记 `rule:<id>`；用户值记 `user:<turn_id>`；查表记 `table:<table_id>`；换算记 `calc:<id>`。用户值永远不被规则覆盖；规则值在每次合并补丁后全部重算（所以改设计压力后默认 PN 会重新取档）。

## 3 尺寸基准与视图

- 立式：模型空间 1:1，设备轴线 x=0，**下封头与筒体的环焊缝 y=0（基准线）**，筒体 y∈[0,L]。卧式：轴线 y=0，**左封头与筒体的环焊缝 x=0**。程序内部统一用“轴向 u、径向 v”的局部坐标画部件，再按立式 (x,y)=(v,u)、卧式 (x,y)=(u,v) 映射。
- 壁厚夸大：图上壁厚 = max(δ·s, 1 mm)/s（s 为主视图比例），向外夸大，Di 不变；尺寸的定义点取**参数值算出的真实位置**，所以尺寸文字就是参数值，尺寸链按参数闭合；技术要求写“壁厚夸大画出”。
- 主视图为全剖：筒体、封头壁剖面涂黑（SOLID 填充，图上壁厚 ≤ 2 mm 时按 GB/T 4457.5 涂黑的阈值待核对），管口开孔处剖面断开。封头开孔处剖面断开只对筒体做，封头部分按简化画法不断开（写进功能对照表）。
- 管口旋转画法：立式方位 [0°,180°) 转到右侧、[180°,360°) 转到左侧；卧式周向角 [270°,90°) 转到上方、[90°,270°) 转到下方。同侧同高度投影重叠时给 `W_ROTATED_OVERLAP`（P0 不画局部视图）。
- 管口方位图（立式俯视）：筒体内外圆、十字中心线、0/90/180/270 标记、每个管口一条径向线（标符号和角度）、封头管口画在其径向位置、耳座位置；约定文字写在图旁。卧式用左视图（外圆 + 鞍座外形 + 管口周向位置）表达方位。
- 布局「设备图」：A1 横放、留装订边；右侧 180 mm 宽一列自下而上：标题栏 → 明细栏 → 管口表 → 设计数据表 → 技术要求；左侧放主视图和方位图/左视图两个视口，各用标准比例并锁定；每个视口一套标注样式（`dimscale` = 比例分母）。

## 5 智能体时序

口令 → 路由（`route` 三分：pfd / general / equipment）→ 设备图时新建 `hg_equipment_a1` 图纸 → Planner（类别含 `chem_equipment` 时拼入设备图一节和 `EQUIP_FEW_SHOTS`）→ `check_plan` + `check_vessel_patch`（数值必须与原话精确相等；可默认字段不在触发词分句里就剔除并警告；“高/长”口径不清转反问）→ 引擎注入 `turn_id` → `vessel_define`（合并 → 默认 → 缺必问项则 `SPEC_INCOMPLETE`，不落版本）→ 引擎把 `SPEC_INCOMPLETE / STD_SIZE_NOT_FOUND / NOZZLE_NO_ROOM / SPEC_CONFLICT / CONFIRM_REQUIRED / NOT_FOUND / AMBIGUOUS` 直接转成反问（问题由代码按 `pending` 拼，mock 与 real 一样，不调模型、不消耗重规划次数）→ 生成 → 自检（错误只把状态降为 READY_WITH_WARNINGS，交付 DXF/PDF 时才拦截）→ 回复里的“按默认”清单由代码按 `defaults_used` 生成。

## 6 路由规则

- 图种词：`(?<!流程)(?:设备图|设备总图|设备装配图)(?!例|形)`、`管口方位图?`、`管口表`、`技术特性表`、`设计数据表`；“装配图/总图/明细栏”只有同句有容器类设备名才计数。
- 设备名 + ≥2 个结构词且无流程词 → equipment；只有一个设备名、没有图种词/结构词/流程词 → equipment 且 `ask_kind=True`（Planner 一次反问图种与必问项）。
- 当前是设备图（`has_vessel`）：只有“流程图/工艺流程/PFD/P&ID/带控制点”才建议新建流程图。
- 误命中修复：“固定管板/固定鞍座/固定端”不算约束类，“N 块塔板/块数”不算块类。
