# 智绘CAD · 化工设计绘图

用一句话画化工图：工艺流程图、化工设备图（立式 / 卧式储罐方案图：装配图、管口方位图、管口表、设计数据表、明细栏）和通用二维 / 三维绘图，都在同一个对话框里完成。大模型只负责理解口令、写参数，几何由确定性程序计算；缺关键参数会反问，不编数值。

- 代码、测试、文档都在 [`app/`](app/)，从 [app/README.md](app/README.md) 开始看。
- 化工设备图：[设计说明](app/01_项目文档/化工设备图_设计说明.md) · [功能对照表](app/01_项目文档/化工设备图_功能对照表.md) · [数据表清单](app/01_项目文档/化工设备图_数据表清单.md) · [变更总结](app/01_项目文档/化工设备图_变更总结.md)

## 运行

需要 Python 3.13 和一个大模型 API Key（默认 DeepSeek）。

```bash
cd app
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
cp 04_后端与部署/.env.example .env      # 填 DEEPSEEK_API_KEY
.venv/Scripts/python -m zhihui.api        # 打开 http://127.0.0.1:8000
```

根目录的 `.bat` 脚本是 Windows 便携部署用的，假定同级有 `runtime/python/python.exe`（便携 Python，体积大，不在仓库里）；部署方式见 [离线部署说明](离线部署说明.md)、[多智能体部署说明](多智能体部署说明.md)。

## 重要说明

- 设备图输出是**方案图**：标准件尺寸（封头、法兰、人孔、支座等）按公开资料录入，**尚未与标准原文核对**，图上已注明；**未做强度计算、开孔补强计算和支座校核，不得直接用于制造**。
- 导出的 DXF 只经过 ezdxf 自检，没有在 AutoCAD / 浩辰 / 中望中逐一验证。
- 标准原文 PDF 版权归出版方，不在仓库里。
